## Selected Engineering Systems

### ALTURA — Hospitality Operations & Controlled AI Workflow System
Hospitality operations case study showing how a guest request becomes a controlled, reviewable workflow from intake through staff decision, narrow action and team handoff.

- **Operational workflow:** Qualifying concierge request → booking-context resolution → deterministic/optional LLM triage → staff approval → action → team handoff.
- **Safety and reliability:** Idempotent intake, Zod-validated analysis with deterministic fallback, approval-gated allowlists, compare-and-set decisions, retries and auditable state transitions.
- **Integration and value:** PostgreSQL-backed operations data, authenticated staff workflows, Slack handoff with a bounded timeout and audited local fallback, plus fixed evaluations and scenario-based value metrics.

**Technology:** React 18 · TypeScript · Node.js · Express · PostgreSQL · Drizzle · Zod · OpenAI · Slack

### AgentOps Command Center — Governed Multi-Agent Operations
Controlled multi-agent operations architecture designed to make non-deterministic LLM workflows observable, testable and human-governed.

- **Architecture:** Typed eight-node state graph across Node/TypeScript and Python/FastAPI: triage, pgvector policy retrieval, specialist review, synthesis, formal approval and finalisation over PostgreSQL.
- **Controls:** Persistence-boundary validation, replayable audit records, deterministic fallback, per-agent model routing, token/latency/cost telemetry and human approval.
- **Verification:** Four golden scenarios and 152 behavioural checks, plus runtime-boundary validation against seeded PostgreSQL.

**Technology:** React 19 · TypeScript · Node.js · Python · FastAPI · PostgreSQL · pgvector · OpenAI

### Aurixa — AI-Enriched Property Operations & Lead Workflow Platform
Commissioned client platform combining a premium React product experience with a production-oriented Strapi/PostgreSQL backend and AI-assisted operational workflows.

- **AI enrichment:** Restb.ai computer vision converts property imagery into structured metadata; OpenAI generates conservative, data-grounded listing copy through an admin-controlled route.
- **Operational handoff:** Sanitised inquiries are persisted before server-side n8n/CRM forwarding with a bounded timeout and recorded delivery status; invalid provider responses abort safely.
